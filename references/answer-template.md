# Candidate answer template

Use this if it helps structure a 5–10 minute response.

## 1. Hypotheses
- Candidate causes and priority
- What each explains / does not explain

## 2. Verification
- First read-only checks
- Timeline and comparison groups
- Command/metric and expected observation

## 3. Decision criteria
- What confirms or rejects each hypothesis
- Evidence limits and remaining uncertainty

## 4. Mitigation
- Smallest safe scope
- Preconditions, capacity, rollback, and risk

## 5. Acceptance
- Business SLI/SLO
- System state and correctness
- Monitoring window and prevention
